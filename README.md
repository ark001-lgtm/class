# 나의 수업 웹앱

소단원마다 만든 전자칠판·아이패드 수업 화면을 한곳에 모아 두고, 해마다 고쳐 가며 쓰는 웹앱입니다.

- 주소 : <https://ark001-lgtm.github.io/class/>
- 로그인도 저장도 없습니다. 수업 중에 쓴 필기와 빈칸은 탭을 닫으면 사라집니다.
- 누구나 주소로 열 수 있는 **공개** 사이트입니다. 학생 이름 같은 개인정보나 교과서 그림을 그대로 옮긴 자료는 넣지 마세요.

## 폴더 한눈에 보기

| 무엇 | 어디 |
|---|---|
| 교과 · 과목 · 단원 · 소단원 목록 | `catalog.json` |
| 소단원 하나 | `lessons/<과목 id>/<소단원 id>/` |
| └ 수업 장면 | `scenes.js` (+ 그 소단원만의 모양 `scenes.css`). 올릴 때 엔진과 합쳐 HTML 하나가 됨 |
| └ 엔진 전에 만든 수업 화면 | `lesson.html` (2-3 열역학 제1법칙). 그대로 씀 |
| 수업 엔진 (무대 · 넘기기 · 펜 필기 · 확대 · 전체 화면 · 테마 · 빈칸) | `engine/` |
| └ 학습지 | `worksheet.pdf` (있으면 [학습지] 단추가 켜짐) |
| └ 수업 메모 | `memo.md` |
| 지난 학년도 판 | `archive/<학년도>/` |
| 허브(첫 화면) 모양과 동작 | `hub/` |
| 합치기 · 미리 보기 · 보관 도구 | `tools/` |

과목 id : 물리학 `physics`, 역학과 에너지 `mechanics-energy`, 고급 물리학 `advanced-physics`.
소단원 id 는 학습지 번호와 같습니다 (예 : 역학과 에너지 `2-3`, 고급 물리학 `04`).

## 자주 하는 일

### 소단원 수업 화면 넣기
소단원 폴더에 장면 파일 `scenes.js` 를 두면 올릴 때 `engine/` 과 합쳐져 HTML 파일 하나가 되고, 허브 카드가 '준비 중'에서 '수업 가능'으로 바뀝니다 (본보기 : `lessons/mechanics-energy/2-5/`).
펜 필기 · 확대 · 전체 화면 같은 공통 부분을 고치려면 `engine/` 만 고치면 됩니다.
다 만든 HTML 파일 하나를 그대로 쓰고 싶으면 `lesson.html` 이름으로 넣어도 됩니다.
학습지는 같은 폴더에 `worksheet.pdf` 로 넣습니다.

### 수업 메모 쓰기
소단원 폴더의 `memo.md` 맨 위쪽에 아래 모양으로 더합니다. 날짜 뒤 반 이름은 써도 되고 안 써도 됩니다.

```
## 2026-11-03 · 2학년 1반
바꾼 것
- 예제 숫자를 바꿈
다음에 바꿀 것
- 단열 장면 설명을 더 짧게
```

맨 위 메모에 **다음에 바꿀 것**이 남아 있으면 카드에 '고칠 것 있음'이 뜹니다. 고친 뒤 새 메모에 '바꾼 것'만 쓰면 다시 '수업 가능'이 됩니다.

### 과목 · 단원 더하기
`catalog.json` 에서 비슷한 덩어리를 복사해 이름만 바꿉니다. id 는 영문 · 숫자 · `-` 로만 씁니다.
교과를 더할 때는 `"name": "과학"` 덩어리를 통째로 복사합니다.
'수업 가능'이어도 잠깐 숨기고 싶으면 소단원 줄에 `"status": "준비 중"` 을 더합니다.

### 내 컴퓨터에서 미리 보기
```
node tools/serve.mjs
```
<http://localhost:4173> 에서 열립니다 (끄기 : Ctrl+C).

### 올리기
GitHub 에 올리면(push) GitHub 가 알아서 합쳐(`tools/build.mjs`) 1~2분 뒤 주소에 반영됩니다.
Claude 에게 "올려 줘"라고 하면 됩니다.

### 학년도 끝에 보관하기
```
node tools/archive.mjs
```
올해 판 전체가 `archive/2026/` 에 그대로 복사되고 `catalog.json` 은 다음 학년도가 됩니다. 올리면 허브 오른쪽 위에 학년도 칸이 생겨 작년 판을 그해 모습 그대로 열 수 있습니다.

## 기기별로 쓰기

- **전자칠판** : 키보드 **F11** 로 브라우저를 전체 화면으로 두면 수업 화면을 열고 닫아도 그대로입니다. 허브의 전체 화면 단추는 수업 화면으로 넘어가면 풀립니다.
- **아이패드** : 사파리에서 주소를 열고 [공유] → [홈 화면에 추가] 하면 앱처럼 열립니다. 한 번 연 뒤에는 인터넷이 끊겨도 열립니다.
- **USB** : 카드의 [내려받기]를 누르면 수업 화면이 HTML 파일 하나로 받아집니다. 인터넷 없이 더블클릭해서 엽니다.
